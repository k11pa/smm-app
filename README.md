# SMM App

Десктопное приложение (Windows), которое заменяет SMM-менеджера: AI помогает со стратегией, контент-планом, постами и публикацией.
Все данные и API-ключи хранятся локально на компьютере пользователя (ключи шифруются средствами Windows).

## Запуск на Windows

1. Установите **Node.js 22 LTS**: https://nodejs.org
2. Установите **Git**: https://git-scm.com/download/win
3. В PowerShell:

```powershell
git clone https://github.com/k11pa/smm-app
cd smm-app
npm install
npm run dev
```

4. В приложении откройте **Settings → AI provider**, вставьте API-ключ и нажмите **Test connection**.

Собрать установщик `.exe`: `npm run dist:win` (файл появится в папке `dist/`).

## Структура

- `src/main` — главный процесс Electron: настройки, шифрование ключей, запросы к AI (ключ не попадает в интерфейс)
- `src/preload` — безопасный мост между интерфейсом и главным процессом
- `src/renderer` — интерфейс на React (языки: English, עברית с RTL, Русский)
- `.claude/agents` — субагенты Claude Code для разработки и SMM-экспертизы
